Course Vision

This isn’t another AI hypefest. It’s a structured deep dive into practical analytic engineering — from folder automation in Stata to API deployment via Render. Rooted in real research needs, delivered by an instructor who’s both a veteran of Stata teaching at Hopkins and now the founder of Ukubona LLC.

🧠 Three Levels of PAIRS Mastery

1. Beginner: Local Stata, Scripted Workflows

  • Generate directory trees with `mkdir`, `cd`, `cap log`, and auto-export zipped bundles
  • Teach collaborators (data guardians, clinicians) without assuming any CLI or code skills
  • Output structured for clean email return or zipped archival

2. Intermediate: GitHub-Driven Local Analysis

  • Run Stata projects locally with GitHub as the backend — no AI, no fuss
  • Minimal dependencies, works offline, version-controlled by default
  • Introduce Codespaces or Binder for `Ukusoma`: cloud-curious collaborators

3. Advanced: VS Code + Copilot + Multi-Kernel .ipynb

  • Jupyter Notebooks with multiple kernels: Python, R, and yes — even Stata
  • Co-Pilot for autocompletion, patterning, docstring generation
  • End-to-end app/API simulation output — `.csv` from Python, `.do` from Stata, `.html` from JS

🌐 From Research Folder to Render API

  • Stata Simulations to `.csv` for ingestion
  • Python Flask backend API (`/simulate`, `/export`)
  • JS/HTML Frontend Dashboard (hosted on GitHub Pages or Render)
  • AI Optional — Used when it helps, ignored when it distracts
